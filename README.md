# AutoLed — 방송 자동화 프로그램 | 오닉소프트(ONICSOFT)

AutoLed는 오닉소프트(ONICSOFT)가 만든 **인터넷 방송 자동화 프로그램**(Windows 앱)입니다.
BJ 후원 알림이 뜨면 정해 둔 OBS 장면 전환, LED 화면, 조명·카메라, 배경음악 음소거를 자동으로 실행하고, 연출이 끝나면 원래 화면으로 돌려놓습니다. 개인방송·엑셀방송·크루방송에서 씁니다.

## 지원하는 것

- 후원 알림: 팬더TV · 투네이션 · 위플랩 · 펀네이션
- 연동: OBS Studio(필수), Resolume, Bitfocus Companion(Stream Deck), 와이와이캠(선택)
- 가로방송 · 세로방송
- Windows 10 · 11

**English** — AutoLed is a Windows broadcast automation app for live streamers, made by ONICSOFT (Korea). When a donation alert appears, it runs the matching OBS scene change, LED (Resolume), lighting/camera (Bitfocus Companion) cues and music muting, then returns to the original scene. This repository only hosts customer installers, signed update metadata, checksums and release notes — no source code or customer configuration. Official page: https://onicsoft.co.kr/autoled.html
